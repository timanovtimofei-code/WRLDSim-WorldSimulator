# WrldSim

Ролевой симулятор жизни на карте мира. Выбираешь эпоху, страну и роль — от нищего до императора, — а сюжет ведёт ECLIPSE Prime, ведущий на языковой модели. Карта — 3D-глобус со спутниковым снимком Земли (или плоская, если нет видеокарты).

## Как запустить

### Вариант 1. Готовая игра (Windows)

1. Откройте [Releases](https://github.com/timanovtimofei-code/WRLDSim-WorldSimulator/releases) и скачайте последний `WrldSim-*.zip`.
2. Распакуйте архив в любую папку. **Не запускайте игру прямо из архива** — рядом с exe должны лежать папки `data` и `saves`.
3. Подключите ведущего (см. «Ключ для ECLIPSE» ниже).
4. Запустите `WRLDSim1.exe`.

Windows может показать «Система Windows защитила ваш компьютер»: у игры нет цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

### Вариант 2. Из исходников

Нужен Python 3.10 или новее.

```
git clone https://github.com/timanovtimofei-code/WRLDSim-WorldSimulator.git
cd WRLDSim-WorldSimulator
pip install -r requirements.txt
python tools/fetch_flags.py
python main.py
```

`fetch_flags.py` один раз скачивает флаги стран. Карта и исторические границы уже лежат в `data/cache/`.

### Ключ для ECLIPSE

ECLIPSE Prime — ведущий игры, он пишет сцены и предлагает действия. Он работает через [OpenRouter](https://openrouter.ai), и **без ключа игра почти не играется**: окна откроются, но ведущий будет молчать.

1. Зарегистрируйтесь на openrouter.ai, пополните баланс на пару долларов (модель платная, но дешёвая — этого хватает надолго).
2. Создайте ключ: Settings → Keys → Create Key.
3. Рядом с `WRLDSim1.exe` (или с `main.py`) создайте файл `.env` — можно переименовать `.env.example` — и впишите в него строку:

```
OPENROUTER_API_KEY=sk-or-ваш-ключ
```

Не делитесь своим ключом: все запросы оплачиваются с вашего баланса.

### Если что-то не работает

| Что происходит | В чём дело |
|---|---|
| ECLIPSE: «Нет ключа…» | нет файла `.env` рядом с игрой или в нём нет строки `OPENROUTER_API_KEY=…` |
| ECLIPSE: «Ключ не принят» | опечатка в ключе или ключ удалён на OpenRouter |
| ECLIPSE: «Не хватает кредитов на счёте OpenRouter» | пополните баланс на openrouter.ai |
| ECLIPSE: «OpenRouter недоступен» | нет интернета или OpenRouter заблокирован в вашей сети |
| exe сразу закрывается | игра запущена из архива или папка `data` лежит не рядом с exe |
| Карта плоская, глобуса нет | видеокарта не поддерживает OpenGL 3.3 — игра переключилась на программный вывод |
| Магазин: «Нет ключа OPENROUTER_API_KEY» | та же причина, что у ECLIPSE |
| Вместо флагов пустые места (вариант 2) | не запущен `python tools/fetch_flags.py` |

Для разработчиков: карту и исторические границы можно пересобрать `tools/build_map.py` и `tools/build_history.py`, exe собирается `build_exe.bat`.

## Как играть

Новая игра → эпоха → режим → страна на глобусе → роль, возраст, пол и имя → игра.

**Эпохи.** Древность (до 1700: Киевская Русь, Рим, Византия, Орда, инки и ещё три десятка государств), эпоха империй (1700–1922) и современность (1922–2026, любая страна мира или СССР, ГДР, Югославия и т. п.). У эпохи свои роли, события, валюта и правила для ведущего — в 1721 году не будет ни полиции, ни новостей.

**Режимы.**
- *Arcade* — песочница: проиграть нельзя, есть случайные события, чит-терминал и откат хода.
- *Realism* — без читов и отката, с уровнями сложности и поражением (смерть, тюрьма, срыв, отставка, банкротство). Ведущий тайно копит на героя компромат, и он может всплыть.

**Игровой экран.** Слева — полоса значков: меню, ECLIPSE, новости, показатели, чит-терминал, «Управление», магазин. Из неё выезжает карточка раздела. В карточке ECLIPSE — сцена, варианты действий и поле для своего действия. Справа сверху — дата, деньги и TIME CONTROL, справа внизу — кнопки карты.

**Управление государством.** Президенту, монарху, канцлеру и другим правителям доступно окно «Управление»: территории, города, бюджет, армия, дипломатия, указы и хроника. Мир живёт сам — соседи воюют, бунтуют и заключают союзы.

**Сохранения.** 15 слотов на режим, у каждого героя свой слот с автосохранением после каждого хода.

## Управление

| Клавиша | Что делает |
|---|---|
| мышь, колесо | вращать глобус, приближать |
| `T` | TIME CONTROL — перемотка времени вперёд и назад |
| `Ctrl+Z` | откат хода (Arcade) |
| `` ` `` или `F1` | чит-терминал (Arcade), `Tab` — одноразовый / постоянный чит |
| `1`–`8` | вкладки окна «Управление» |
| `F11` | полный экран |

Встроенные читы: `деньги 5 млн`, `деньги = 1 млрд`, `здоровье 100`, `внимание 0`, `пропусти 30 дней`, `новость: текст`, `help`. Всё остальное разбирает модель.

## Настройки

Режим окна, вид интерфейса (плоский или «Стекло»), глобус или плоская карта и цвет акцента. Всё хранится в `settings.json`.

## Для разработки

```
wrldsim/
  app.py, gpu.py   главный цикл и OpenGL-вывод (карта, глобус, стекло)
  map/             карта: данные, камера, отрисовка, флаги, подписи
  history/         исторические границы по эпохам
  sim/             ядро игры, живой мир, ECLIPSE, читы, магазин, сохранения
  states/          экраны
  ui/              тема, шрифты, кнопки и поля, значки
data/              баланс, эпохи, роли, промпты, текстуры
tools/             сборка карты и исторических границ, загрузка флагов, ui_check.py
```

`python tools/ui_check.py` прогоняет все экраны без окна в трёх размерах, кликает окна и сохраняет скриншоты в `build/ui_check/`. Сеть при этом отключена, сейвы не трогаются.
