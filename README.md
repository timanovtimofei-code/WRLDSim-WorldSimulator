# WrldSim

Ролевой симулятор жизни на карте мира. Выбираешь эпоху, страну и роль — от нищего до императора, — а сюжет ведёт ECLIPSE Prime, ведущий на языковой модели. Карта — 3D-глобус со спутниковым снимком Земли (или плоская, если нет видеокарты).

## Запуск

```
pip install -r requirements.txt
python tools/fetch_flags.py   # один раз: флаги стран → data/flags/
python main.py
```

Ключи API кладутся в `.env` рядом с `main.py` или exe (образец — `.env.example`):

- `OPENROUTER_API_KEY` — ECLIPSE Prime, магазин и чит-терминал;
- `DEEPSEEK_API_KEY` — необязательно, чит-терминал пойдёт напрямую в DeepSeek.

Без ключей игра запускается, но ведущий молчит, а в терминале работают только встроенные команды.

Карта и исторический атлас уже собраны и лежат в `data/cache/`; пересобрать их можно скриптами `tools/build_map.py` и `tools/build_history.py`.

Сборка exe: `build_exe.bat` → `WRLDSim1.exe`. Рядом с ним должны лежать `data/`, `saves/`, `.env` и `settings.json`. Данные и промпты можно править без пересборки.

## Как играть

Новая игра → эпоха → режим → страна на глобусе → роль, возраст, пол и имя → игра.

**Эпохи.** Древность (до 1700: Киевская Русь, Рим, Византия, Орда, инки и ещё три десятка государств), эпоха империй (1700–1922) и современность (1922–2026, любая страна мира или СССР, ГДР, Югославия и т. п.). У эпохи свои роли, события, валюта и правила для ведущего — в 1721 году не будет ни полиции, ни новостей.

**Режимы.**
- *Arcade* — песочница: проиграть нельзя, есть случайные события, чит-терминал и откат хода.
- *Realism* — без читов и отката, с уровнями сложности и поражением (смерть, тюрьма, срыв, отставка, банкротство). Ведущий тайно копит на героя компромат, и он может всплыть.

**Игровой экран.** Слева — полоса значков: меню, ECLIPSE, новости, показатели, чит-терминал, «Управление», магазин. Из неё выезжает карточка раздела. В карточке ECLIPSE — сцена, варианты действий и поле для своего действия. Справа сверху — дата, деньги и TIME CONTROL, справа внизу — кнопки карты.

**Управление государством.** Президенту, монарху, канцлеру и другим правителям доступно окно «Управление»: территории, города, бюджет, армия, дипломатия, указы и хроника. Мир живёт сам — соседи воюют, бунтуют и заключают союзы.

**Сохранения.** 15 слотов на режим, у каждого героя свой слот с автосохранением после каждого хода.

## Управление

| Клавиша | Что делает |
|---|---|
| мышь, колесо | вращать глобус, приближать |
| `T` | TIME CONTROL — перемотка времени вперёд и назад |
| `Ctrl+Z` | откат хода (Arcade) |
| `` ` `` или `F1` | чит-терминал (Arcade), `Tab` — одноразовый / постоянный чит |
| `1`–`8` | вкладки окна «Управление» |
| `F11` | полный экран |

Встроенные читы: `деньги 5 млн`, `деньги = 1 млрд`, `здоровье 100`, `внимание 0`, `пропусти 30 дней`, `новость: текст`, `help`. Всё остальное разбирает модель.

## Настройки

Режим окна, вид интерфейса (плоский или «Стекло»), глобус или плоская карта и цвет акцента. Всё хранится в `settings.json`.

## Для разработки

```
wrldsim/
  app.py, gpu.py   главный цикл и OpenGL-вывод (карта, глобус, стекло)
  map/             карта: данные, камера, отрисовка, флаги, подписи
  history/         исторический атлас по эпохам
  sim/             ядро игры, живой мир, ECLIPSE, читы, магазин, сохранения
  states/          экраны
  ui/              тема, шрифты, кнопки и поля, значки
data/              баланс, эпохи, роли, промпты, текстуры
tools/             сборка карты и атласа, загрузка флагов, ui_check.py
```

`python tools/ui_check.py` прогоняет все экраны без окна в трёх размерах, кликает окна и сохраняет скриншоты в `build/ui_check/`. Сеть при этом отключена, сейвы не трогаются.

## Источники
